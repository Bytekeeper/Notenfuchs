# Datenschutz

Diese Seite gilt für die Website von Notenfuchs, nicht für die App. Eine Notenfuchs-Instanz
läuft auf dem Server, der sie betreibt, und sendet keine Daten an das Projekt.

## Besucherstatistik

Wir zählen Seitenaufrufe mit [GoatCounter](https://www.goatcounter.com/), das wir selbst
unter stats.bytekeeper.org betreiben. GoatCounter setzt keine Cookies. Um mehrfache Aufrufe
derselben Person zu erkennen, hält es eine Kennung aus Website, Browser-Kennung und
IP-Adresse höchstens 8 Stunden im Arbeitsspeicher. IP-Adresse und Browser-Kennung werden nie
gespeichert. Gespeichert werden nur Summen: welche Seiten aufgerufen wurden, von welcher
Website Besucher kamen, Land, Browser, Betriebssystem und Bildschirmgröße. Die Daten
verlassen unseren Server nicht und gehen an keine anderen Anbieter.

## Hosting

Die Website liegt bei GitHub Pages. GitHub verarbeitet beim Aufruf technische Daten wie die
IP-Adresse; Einzelheiten stehen in der
[Datenschutzerklärung von GitHub](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement).
